Frontend Development

Assessment emphasis: HTML 20%, CSS 30%, JavaScript 30%, and interface design 20%.

Module 1 HTML Fundamentals

Semantic document structure, content elements, links, media, lists, and forms.

  1. Introduction to HTML: web pages, document structure, doctype, html, head, and body.
  2. Elements: tags, opening/closing tags, attributes, and nesting.
  3. Headings and text: h1-h6, paragraphs, line breaks, and thematic breaks.
  4. Links: relative and external URLs, fragments, and target behavior.
  5. Images: src, alt, width, height, and descriptive alternatives.
  6. Lists: ordered, unordered, and description lists.
  7. Forms: labels, text/email/password/number inputs, radio, checkbox, select, textarea, and submit.
  8. Semantic HTML: header, nav, main, section, article, aside, and footer.
HTML coding assessment

Create a student registration form with name, email, password, gender, course selection, labels, and submit control.

Module 2 CSS Fundamentals

Style semantic page structures with maintainable rules and reusable design values.

  1. CSS purpose and inline, internal, and external stylesheets.
  2. Selectors: element, class, ID, universal, grouped, and attribute selectors.
  3. Colors and backgrounds: text color, background-color, and background-image.
  4. Typography: font family, size, weight, alignment, decoration, and line height.
  5. Box model: content, padding, border, margin, dimensions, and box-sizing.
  6. Display values: block, inline, inline-block, and none.
  7. Positioning: static, relative, absolute, fixed, and sticky.
  8. Flexbox: direction, alignment, wrapping, and gap.
  9. Grid: rows, columns, tracks, and gaps.
  10. Pseudo-classes: hover, active, visited, focus, first-child, and last-child.
  11. Stacking: z-index and stacking contexts.
  12. Responsive design: mobile, tablet, desktop, and media queries.
CSS coding assessment

Create a student profile card that changes from a three-column desktop layout to one column on mobile.

Module 3 Responsive Design

Make layouts adapt to viewport width, touch input, content length, and accessibility preferences.

  • Mobile-first constraints and flexible sizing.
  • Breakpoints and media-query ordering.
  • Responsive images and readable text measures.
  • Navigation patterns for narrow screens.
  • Overflow testing and touch target sizing.
  • Reduced-motion preferences and keyboard focus.
Practice: resize a course dashboard and remove horizontal overflow without hiding important content.
Module 4 JavaScript Basics

Introduce the browser programming concepts needed for full-stack interfaces.

  1. What JavaScript does with HTML and CSS.
  2. Variables: var, let, and const.
  3. Types: strings, numbers, booleans, undefined, null, objects, and arrays.
  4. Arithmetic, comparison, logical, and assignment operators.
  5. if, else if, else, and switch.
  6. for, while, and do-while loops.
  7. Functions, parameters, and return values.
  8. Array operations: push, pop, shift, unshift, slice, and splice.
  9. Objects and property access.
  10. DOM selection: getElementById, querySelector, and querySelectorAll.
  11. Events: click, submit, change, keyup, and mouseover.
  12. Form validation and useful error messages.
JavaScript assessment topic

Build a student registration form that validates required fields and displays clear errors.

Module 5 Frontend Project

Combine page structure, layout, responsive behavior, and browser interaction in a learning portal.

  • Home register login dashboard courses curriculum concept quiz.
  • Course cards, progress visualizations, module navigation, and quiz screens.
  • Keyboard navigation, labels, responsive layouts, and useful empty states.
Frontend final assessment

Create a responsive course dashboard with course cards, progress bars, modules, concept pages, and a quiz interface.

Python + Backend Development

Build programming fluency first, then apply it to web applications and APIs.

Module 1 Python Fundamentals

Install and run Python, understand values, and write basic programs.

  • Python features, interpreter, installation, and running scripts.
  • Variables and assignment.
  • Types: int, float, str, bool, and complex.
  • input(), print(), and type conversion.
  • Arithmetic, comparison, logical, assignment, membership, identity, and bitwise operators.
  • if, elif, else; for and while; break, continue, and pass.
Practice

Read a student's marks and display a grade with a clear boundary rule.

Module 2 Python Data Structures

Choose the right collection, update it safely, and solve common list problems.

  • Lists: append, insert, remove, pop, sort, and reverse.
  • Tuples: construction, indexing, slicing, packing, and unpacking.
  • Sets: add, remove, union, intersection, and difference.
  • Dictionaries: keys, values, items, get, and update.
  • Nested collections and loops over structured data.
Practice: second-largest value duplicate detection frequency counts maximum subarray sum.
Module 3 Strings

Work with text as an indexed sequence and apply common transformations.

  • Creation, indexing, slicing, formatting, and immutability.
  • Methods: upper, lower, strip, replace, split, join, find, and count.
  • String reversal, palindrome checks, and anagram checks.
Practice: normalize text and explain how punctuation and letter case affect a palindrome check.
Module 4 Functions

Write reusable functions with clear inputs, outputs, and responsibilities.

  • def, return, parameters, positional and keyword arguments.
  • Default arguments, *args, and **kwargs.
  • Lambda expressions and recursion.
Practice

Write separate calculator functions and test division-by-zero behavior.

Module 5 Object-Oriented Programming

Represent domain concepts through state and behavior.

  • Classes, objects, constructors, and __init__().
  • Instance variables, class variables, and methods.
  • Single, multiple, multilevel, and hierarchical inheritance.
  • Polymorphism, encapsulation, and abstraction.
Practice: model Student, Teacher, and Course with clear responsibilities.
Module 6 Exception Handling

Handle failures deliberately and show useful recovery behavior.

  • try, except, else, finally, and raise.
  • ValueError, division by zero, missing files, and invalid input.
  • Catch specific exceptions and avoid silently swallowing errors.
Practice: build a safe calculator that reports invalid operations clearly.
Module 7 File Handling

Read and write files safely, then use structured formats.

  • open, read, write, append, close, and context managers.
  • Modes: r, w, a, and x.
  • CSV and JSON basics.
Practice: create a student record file and reload records on program start.
Module 8 Advanced Python

Understand common language tools and organize reusable code.

  • List and dictionary comprehensions.
  • Iterators and generators.
  • Decorators, modules, and packages.
  • Virtual environments and pip.
Practice

Create a small utility package containing validated reusable functions.

Module 9 Django Fundamentals

Use Django to route requests and render application responses.

  • Django purpose and project architecture.
  • Project and app creation; URL patterns and views.
  • Request URL view model/template response lifecycle.
  • Templates: inheritance, variables, loops, conditions, and filters.
  • Static assets and settings.
django-admin startproject learning_platform
python manage.py startapp students
Module 10 Django Models

Represent application data and evolve the database schema.

  • Model fields: CharField, EmailField, IntegerField, DateField, BooleanField, and TextField.
  • One-to-one, one-to-many, and many-to-many relationships.
  • makemigrations, migrate, model validation, and Django admin.
python manage.py makemigrations
python manage.py migrate
Module 11 Django Authentication

Understand registration, sign-in, sign-out, profiles, sessions, and authorization.

  • Use Django's authentication framework rather than hand-rolling password storage.
  • Registration and login views, logout, and profile data.
  • Permissions and role-aware views.
  • CSRF protection, safe redirects, and secure configuration.
Student flow: register sign in dashboard.
Module 12 Django Backend for the Learning Platform

Model the complete learning journey and its assessments.

  • Entities: Student, Course, Module, Concept, Quiz, Question, Answer.
  • Progress and results: StudentProgress, CourseResult, FinalResult, Certificate.
  • Define ownership, relationships, permissions, and completion rules.
  • Only issue a certificate after server-verified assessment completion.
Relationship: Student Enrollment/Progress Course Module Concept Quiz Question/Answer.
Module 13 Django REST API

Exchange structured data between a frontend and backend with HTTP APIs.

  • API, JSON, HTTP, GET, POST, PUT/PATCH, and DELETE.
  • Serializers, views/viewsets, routers, validation, and status codes.
  • Pagination, permissions, error responses, and API documentation.
  • Example routes: GET /api/courses/ POST /api/register/ GET /api/student/progress/ POST /api/quiz/submit/.
Backend assessment checklist

Create the Django project, student authentication, course/module/concept management, quiz submission, progress tracking, course test, final test, and server-generated certificate.

Database Development

Use SQL and MySQL concepts to build a normalized learning-platform data model.

Module 1 Database Fundamentals

Understand data storage and relational database terminology.

  • Data, databases, DBMS, RDBMS, SQL, and MySQL.
  • Tables, rows, columns, records, and data types.
Module 2 SQL Fundamentals

Define and query relational structures.

  • DDL: CREATE, ALTER, DROP, and TRUNCATE.
  • DML: INSERT, UPDATE, and DELETE.
  • DQL: SELECT, filtering, sorting, and projection.
Module 3 Constraints

Protect data quality with database-enforced rules.

  • PRIMARY KEY, FOREIGN KEY, UNIQUE, NOT NULL, DEFAULT, and CHECK.
  • Referential integrity and deliberate delete/update behavior.
CREATE TABLE students (
  id INT PRIMARY KEY,
  name VARCHAR(100) NOT NULL,
  email VARCHAR(100) UNIQUE
);
Module 4 CRUD

Create, read, update, and delete records using parameterized statements.

  • INSERT rows with valid fields.
  • SELECT useful subsets.
  • UPDATE and DELETE with precise WHERE clauses.
Module 5 SQL Operators

Filter and compare values with common SQL operators.

  • Arithmetic, comparison, and logical operators.
  • BETWEEN, IN, LIKE, and IS NULL.
  • NULL comparisons and safe filtering.
Module 6 Aggregate Functions

Summarize groups of records.

  • COUNT(), SUM(), AVG(), MIN(), and MAX().
  • Handling NULL values and interpreting result sets.
Module 7 GROUP BY and HAVING

Aggregate by category and filter aggregate results.

  • GROUP BY columns and aggregate expressions.
  • WHERE filters rows; HAVING filters groups.
SELECT course_id, COUNT(*)
FROM enrollments
GROUP BY course_id;
Module 8 Joins

Combine related rows across normalized tables.

  • INNER JOIN, LEFT JOIN, RIGHT JOIN, CROSS JOIN, and self joins.
  • Join keys, aliases, and avoiding duplicate rows.
Module 9 Subqueries

Use a query result inside another query where appropriate.

  • Subqueries in SELECT, FROM, and WHERE.
  • Scalar and multi-row subqueries; EXISTS basics.
SELECT name
FROM students
WHERE marks > (SELECT AVG(marks) FROM students);
Module 10 Normalization

Reduce avoidable duplication and update anomalies.

  • 1NF, 2NF, and 3NF.
  • Functional dependencies and candidate keys.
  • Trade-offs between normalization and query simplicity.
Module 11 Learning Platform Database Design

Plan normalized tables and useful queries for the complete learning platform.

  • Tables: students, courses, modules, concepts, quizzes, questions, answers, enrollments, student_progress, course_results, final_results, and certificates.
  • Define primary/foreign keys, unique constraints, timestamps, and ownership.
  • Write queries for progress, quiz scores, course results, and eligible certificates.
  • Design a data dictionary and relationship diagram before implementation.
Final database assessment

Design the complete Student Learning Platform schema and write CRUD, JOIN, aggregate, and progress-report queries.
