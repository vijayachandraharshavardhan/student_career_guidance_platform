Course curriculum

Module 1 · Modern JavaScript

Learn

Understand values, variables, functions, modules, arrays, objects, and asynchronous work. const prevents rebinding; let supports reassignment. Promises represent work that completes later, and async/await makes asynchronous control flow easier to read.

Example
const courseNames = courses.map(course => course.title);
Practice

Transform an array of course objects into a list of display labels.

Self-check

What does await do inside an async function?

Correct. await lets the async function continue after settlement.

await works with Promises inside async functions.

Module 2 · Node.js and package tooling

Learn

Node runs JavaScript outside the browser. npm manages packages and scripts. Keep dependencies explicit, separate development tooling from runtime packages, and use environment variables for configuration rather than hard-coded secrets.

Practice

Create a Node project with a start script and a small module that formats course data.

Self-check

What is Node.js?

Correct. Node runs JavaScript outside a browser.

Node.js is a JavaScript runtime.

Module 3 · HTTP, APIs, and Express

Learn

HTTP requests carry a method, path, headers, and optional body. Express routes requests through middleware and handlers. Keep routing, validation, business logic, and error handling understandable.

Practice

Create a GET route that returns a JSON array of available courses.

Self-check

What is Express commonly used for?

Correct. Express provides server routing and middleware patterns.

Express is a Node web framework.

Module 4 · MongoDB and document modeling

Learn

MongoDB stores BSON documents in collections. Model documents around application access patterns; use validation, indexes, and references where they make relationships and queries clear. Avoid treating a flexible schema as a reason to omit design.

Practice

Design a course document with modules and decide which data should be referenced separately.

Self-check

What does a MongoDB collection contain?

Correct. Collections group documents.

MongoDB stores documents in collections.

Module 5 · Data access and CRUD APIs

Learn

CRUD routes create, read, update, and delete resources. Validate payloads, scope updates to the requested resource, and return useful status codes. Use pagination for growing lists and never trust unvalidated client input.

Practice

Plan REST routes for courses and enrollments, including invalid-id and missing-resource responses.

Self-check

Why validate a request body on the server?

Correct. The server is the trusted validation boundary.

A client can be modified; validate data at the server.

Module 6 · React components and JSX

Learn

React components compose an interface. JSX describes rendered elements; props pass inputs to a component. Keep components focused, choose semantic HTML, and provide accessible names for interactive controls.

Practice

Create a CourseCard component that displays a title, summary, and accessible action link.

Self-check

What do props provide to a component?

Correct. Props are component inputs.

Props pass values into a component.

Module 7 · State, forms, and navigation

Learn

State represents values that change over time. Controlled forms keep input values in component state, validation provides feedback, and routing connects views. Avoid storing secrets or authoritative permission decisions in client state.

Practice

Build a registration view with labeled inputs and clear validation messages.

Self-check

What should happen after state changes?

Correct. State changes cause the relevant interface to update.

State drives the rendered interface.

Module 8 · Connect React to APIs

Learn

The client requests API data and should represent loading, success, empty, and failure states. Handle rejected requests, parse JSON intentionally, and keep user feedback aligned with the request result.

Practice

Fetch a course list and display loading, error, empty, and populated states.

Self-check

Why show a loading state?

Correct. Loading feedback communicates in-progress work.

Represent request progress clearly in the interface.

Module 9 · Authentication and authorization

Learn

Authentication establishes identity; authorization checks permission. Use server-managed sessions or carefully managed tokens, hash passwords on the server, and protect routes and records. A hidden React component does not secure an endpoint.

Practice

Define student and admin actions, then list the server-side authorization check for each.

Self-check

Is hiding an admin link enough to protect an admin API?

Correct. Protect the API on the server.

UI visibility is not authorization.

Module 10 · Full-stack application structure

Learn

Separate client presentation, API routes, business rules, and persistence. Define contracts between layers, use configuration per environment, and return consistent errors. Keep responsibilities small enough to test and evolve.

Practice

Draw the request flow for course enrollment from React form through Express route to MongoDB.

Self-check

Where should authoritative business rules live?

Correct. Enforce authoritative rules on the server.

Server-side rules protect data regardless of client behavior.

Module 11 · Testing and debugging

Learn

Unit tests verify focused logic, API tests exercise server contracts, and component tests cover interface behavior. Reproduce bugs, inspect logs and browser tools, and change one cause at a time.

Practice

Test a validation helper, an API error response, and a React empty state.

Self-check

What is a unit test intended to examine?

Correct. Unit tests focus on small units of behavior.

Keep unit tests focused and isolated.

Module 12 · Security, performance, and accessibility

Learn

Validate input, use safe database access, protect secrets, rate-limit sensitive operations, and check authorization. Improve slow queries with measurement. Accessibility includes semantics, labels, keyboard support, focus visibility, and understandable errors.

Practice

Review a course form for keyboard access, validation, and unsafe input handling.

Self-check

Which practice protects secrets?

Correct. Keep secrets out of browser bundles and source control.

Secrets belong in protected server-side configuration.

Module 13 · Deployment and operations

Learn

Prepare production builds, environment configuration, database connectivity, health checks, logs, and rollback procedures. Deployment is an operational process as well as a build command.

Practice

Write a deployment checklist covering configuration, migrations, health checks, and recovery.

Self-check

Why separate configuration from source code?

Correct. Configuration varies by environment and may contain secrets.

Configuration should be explicit and environment-aware.

Module 14 · MERN Capstone

Build and present a complete application

Combine React, Express, Node, and MongoDB in a focused product. Define the user journey, data model, API contract, test strategy, and release plan. Document setup and known limitations.

Capstone

Build a course portal with registration, course browsing, progress tracking, and an assessment workflow.

Self-check

What should a capstone README include?

Correct. Document how to understand and run the project.

Explain setup, architecture, tests, and limitations.
