Python foundations · 8 modules

Full-stack foundations

Module 1 · Python Fundamentals

Learn

Install and run Python. Use variables, strings, numbers, booleans, input/output, operators, conditions, and loops. Convert user input explicitly and validate boundaries.

Example
topic = input("Study topic: ").strip()
minutes = int(input("Minutes available: "))
Practice

Read a study topic and time budget, validate the values, and show a focused next step.

Self-check

What does input() return by default?

Correct. Convert input text before numeric calculations.

input() returns a string.

Module 2 · Control Flow and Functions

Learn

Use conditional branches, loops, and focused functions to express program behavior. Functions take parameters and return useful results. Handle invalid input near its boundary.

Practice

Write a function that divides study time into focus sessions and validates its arguments.

Self-check

What does return do in a function?

Correct. The caller can use the returned value.

return sends a result back to the caller.

Module 3 · Collections and Object-Oriented Python

Learn

Use lists, dictionaries, tuples, and sets to represent information. Classes combine state and behavior when a domain concept needs a clear model. Prefer composition and simple responsibilities.

Practice

Model a document chunk with text, source title, and metadata; store several chunks in a collection.

Self-check

Which Python collection maps keys to values?

Correct. A dictionary stores key/value pairs.

Choose dict for key/value data.

Module 4 · APIs, HTTP, and Data Formats

Learn

HTTP requests carry methods, paths, headers, and optional bodies. JSON represents structured data. APIs define how services communicate; predictable status codes and error messages make them easier to consume.

Practice

Write an example JSON request for a career recommendation and identify which fields require validation.

Self-check

Which format is commonly exchanged by web APIs?

Correct. JSON commonly represents API data.

Web APIs commonly exchange JSON.

Module 5 · HTML, CSS, and JavaScript

Learn

Create semantic browser pages, responsive layouts, labeled forms, and clear interaction states. Accessible interface patterns matter just as much for AI features as for ordinary forms.

Practice

Sketch and build a responsive assistant interface with prompt input, source area, loading state, and error message.

Self-check

What should every form input have?

Correct. Labels identify controls to people and assistive technology.

Provide a visible, associated label.

Module 6 · Django or FastAPI Web Foundations

Learn

Route requests to Python handlers, validate input, and return structured responses. Organize configuration and code so the web boundary stays distinct from domain behavior.

Practice

Create a health-check route and a route that validates a simple recommendation request.

Self-check

What does a route connect?

Correct. Routes map URL patterns to handlers.

A route directs a request to a handler.

Module 7 · Database Design and Persistence

Learn

Store users, source documents, course content, and application records with clear relationships. Use migrations, constraints, and transactions to keep persistent state coherent.

Practice

Sketch tables for AI documents, chunks, and references back to their source.

Self-check

Why persist source metadata with a retrieved chunk?

Correct. Metadata helps trace and cite source material.

Keep source identity so retrieved evidence can be traced.

Module 8 · Authentication, Privacy, and Security

Learn

Keep identity checks, permissions, and secrets on the protected server. Collect only needed data, define retention expectations, and restrict access to user prompts and uploaded documents.

Practice

Threat-model a student assistant that accepts private course notes and returns study guidance.

Self-check

Where should a model API key be stored?

Correct. Do not expose provider credentials in the browser.

Keep provider secrets server-side.

Module 9 · Generative AI and Language-Model Basics

Learn

Language models generate likely continuations from input context. Tokens and context-window limits affect cost and available context. Model outputs can be plausible but incorrect; treat them as untrusted until checked.

Practice

Compare two model answers and identify which factual claims need evidence.

Self-check

Can a fluent model answer still contain an error?

Correct. Evaluate model outputs rather than assuming correctness.

Fluency is not evidence of factual accuracy.

Module 10 · Prompt Design and Structured Output

Learn

State the task, relevant context, constraints, and expected output format. Examples can clarify structure. Structured output makes downstream validation easier but does not make content inherently true.

Practice

Write a prompt that returns a study plan with topic, duration, and cited source fields in a fixed schema.

Self-check

What improves prompt clarity?

Correct. Specify the task and desired response structure.

Make the task, context, constraints, and output explicit.

Module 11 · Model APIs and Safe Key Handling

Learn

Call providers from a server with timeouts, bounded retries, quota handling, and input/output validation. Keep credentials out of repositories and browser bundles. Log useful operational metadata without exposing sensitive prompt contents.

Practice

Design error handling for timeout, rate limit, invalid response, and provider outage cases.

Self-check

Why set a timeout on a model API request?

Correct. Timeouts prevent a request from waiting indefinitely.

Timeouts make slow or stuck requests recoverable.

Module 12 · Embeddings and Semantic Search

Learn

Embeddings map text to numeric vectors that can support semantic similarity search. Chunk documents thoughtfully, preserve metadata, select an index for the dataset, and inspect retrieval quality rather than assuming nearest neighbors are relevant.

Practice

Split a short course guide into chunks and record a title, section, and source for each one.

Self-check

What are embeddings commonly used for?

Correct. Embeddings are vector representations used for similarity tasks.

Embeddings represent data as vectors; compare them for similarity.

Module 13 · Retrieval-Augmented Generation

Learn

RAG retrieves relevant source chunks and adds them to model context. A basic pipeline ingests documents, chunks and indexes them, retrieves candidates for a question, and produces an answer grounded in that evidence. Show citations and handle cases where retrieval finds no useful source.

Pipeline
Question → retrieve sources → build context → generate response → cite sources
Practice

Design a course FAQ response that cites the source lesson and abstains when no relevant material is found.

Self-check

What does retrieval add to a generation prompt?

Correct. Retrieval supplies relevant context, not a guarantee.

Retrieval supplies evidence to the model; it cannot guarantee truth.

Module 14 · Evaluation, Safety, and Responsible Use

Learn

Define a representative evaluation set and inspect answer quality, source relevance, refusal behavior, latency, and cost. Test prompt injection, privacy exposure, harmful outputs, and unsupported claims. Keep a human review path for consequential decisions.

Practice

Write test cases for correct source use, irrelevant retrieval, missing evidence, prompt injection, and private data.

Self-check

What should evaluation measure?

Correct. Evaluate the outcomes and operational risks that matter.

Measure quality and safety as well as cost and latency.

Module 15 · Full-Stack AI Product Integration

Learn

Connect an accessible client to a protected Python service, database, retrieval layer, and provider API. Design loading, cancellation, streaming concepts, errors, rate limits, logs, and user controls around the AI feature.

Practice

Map the request from a student question to retrieved documents, model response, cited result, and saved feedback.

Self-check

Where should a browser UI send its AI request?

Correct. Keep credentials and policy checks on the server.

Send requests through your protected backend.

Module 16 · Capstone: Grounded Career Assistant

Build the product

Create an assistant that answers from a curated career-learning source set, links evidence, supports user feedback, and reports when it lacks enough context. Document the evaluation set, safety checks, cost boundaries, and known limitations.

  • Responsive client and accessible conversation controls.
  • Python API, data store, retrieval, and model integration.
  • Source references, abstention behavior, and evaluation.
  • Demo, setup instructions, and responsible-use notes.
Capstone review

Present one failure discovered during evaluation and the change made to improve reliability.

Self-check

What should a responsible capstone document?

Correct. Document how the system works and where it may fail.

Include setup, evidence, evaluation, safety, and limitations.
